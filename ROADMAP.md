# 2D-RPG — Roadmap (reset 2026-09-05)

Hardcore, **offline**, pixel-art 2D RPG for Android. Godot 4.4. Bilingual EN/FA
with real RTL + Persian numerals.

> This roadmap replaces the previous one. The old roadmap claimed Phases 0–11
> complete; an audit against the actual code (see
> `docs/AUDIT_OF_PREVIOUS_BUILD.md`) showed the project did not compile, 11 of
> 14 autoloads failed, and no gameplay system was wired to any input. The
> project was therefore **rebuilt from scratch** on branch `rebuild/pixel-art`.
>
> **Rule for this roadmap: a milestone is only "done" when a named automated
> check or screenshot proves it.** No self-reported checkmarks.

---
