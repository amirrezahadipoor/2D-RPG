# 2D-RPG — Roadmap (reset 2026-09-05)

Hardcore, **offline**, pixel-art 2D RPG for Android. Godot 4.4. Bilingual EN/FA
with real RTL + Persian numerals.

> This roadmap replaces the previous one. The old roadmap claimed Phases 0–11
> complete; an audit against the actual code (see
> `docs/AUDIT_OF_PREVIOUS_BUILD.md`) showed the project did not compile, 11 of
> 14 autoloads failed, and no gameplay system was wired to any input. The
> project was therefore **rebuilt from scratch** on branch `rebuild/pixel-art`.
>
> **Rule for this roadmap: a milestone is only "done" when a named automated
> check or screenshot proves it.** No self-reported checkmarks.

---

## M0 — Foundation: it boots, it renders, it's solid  ✅ DONE

Evidence: `tests/verify.tscn` (74 checks), `docs/screenshots/01_world.png`.

- [x] Project imports with **0 errors and 0 warnings** (warnings are ON)
- [x] Pixel-art pipeline: native 480×270, `stretch=viewport`, integer scale,
      nearest filtering, pixel snapping
- [x] Real committed pixel-art assets generated by `tools/gen_assets.py`
      (hero, 26 equipment pieces, 12 terrain tiles, 8 props, 7 enemies, icons)
- [x] Procedural overworld from coherent `FastNoiseLite` (7 biomes), rendered
      with `TileMapLayer`
- [x] Tile collision with correct centre-relative polygons; no tunneling
- [x] Hero: 8-way movement, acceleration/friction, real `CollisionShape2D`,
      `Camera2D` as a **child** of the hero with smoothing + world limits
- [x] Live HUD (HP/stamina/level/gold/biome/gear icons) driven by signals
- [x] I18N: bundled Vazirmatn (OFL), EN/FA, RTL, Persian digits, hotkey `L`
- [x] Headless self-test suite that **exits non-zero on failure**
- [x] CI that runs the import + the suite and fails on error

## M1 — Paper-doll equipment + combat feel  ✅ DONE

Evidence: `tests/verify.tscn` (74 checks), `docs/screenshots/05_combat.png`,
`06_death_hardcore.png`, `07_death_fa.png`.

- [x] Paper-doll: 7 synced sprite layers
      (accessory → body → legs → boots → chest → helmet → weapon);
      equipping changes the character on screen in all 4 directions

- [x] Gear cycling demo hotkey `G`
- [x] Enemies spawn in the world (biome-aware, capped, culled), chase, wind up,
      attack, die and pay XP/gold — checks: `enemy chases…`, `kill pays xp/gold`
- [x] Damage numbers + hit flash + screenshake + hurt vignette + death puffs
      (`src/autoload/juice.gd`, visible in `05_combat.png`)
- [x] Weapon reach/damage/cooldown/stamina/knockback differ per weapon
      (`src/data/weapons.gd`; check: `axe swing hits harder than dagger`)
- [x] Armor from worn gear reduces incoming damage (min 1 per hit)
- [x] Death + hardcore permadeath flow: `Game.State.DEAD`, death screen with run
      summary (EN+FA/RTL), hardcore deletes `user://savegame.save`
      (checks: `hardcore death deletes the save file`,
      `non-hardcore death keeps the save`)

## Verification commands

```bash
# import must be clean (0 errors / 0 warnings)
godot --headless --path . --import

# automated checks (exits non-zero on failure)
godot --headless --path . res://tests/verify.tscn

# real rendered screenshots (needs a display; xvfb-run works)
xvfb-run -a -s "-screen 0 1440x810x24" godot --path . res://tools/screenshot.tscn

# regenerate all pixel art (CI asserts the committed PNGs match this)
python3 tools/gen_assets.py
```
